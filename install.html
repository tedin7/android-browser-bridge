BROWSER BRIDGE · IL TUO BROWSER, I TUOI SERVER

Collega Firefox.
Lavora dai tuoi terminali.

Una sola estensione sul tablet, più server Linux autorizzati. Nessun ADB, cavo o servizio centrale.

Tre passi per collegarti

  1. Installa Browser Bridge in Firefox Android.
  2. Chiedi all’assistente sul Linux: «Collega il mio browser con Browser Bridge». Riceverai un codice BB1.…, valido cinque minuti.
  3. Apri Browser Bridge dal menu Estensioni. Nella sezione Aggiungi un collegamento, incolla il codice, scegli un nome e autorizza il controllo.

Ogni server appare nella propria scheda: stato, indirizzo e pulsanti per metterlo in pausa o scollegarlo. Puoi fermarli tutti con un solo interruttore.

Scarica estensione di sviluppo

Build di sviluppo non firmata. Richiede il percorso di installazione Nightly documentato. La pubblicazione su Mozilla Add-ons è ancora in preparazione: questo download non è una versione approvata dallo store.

Reti diverse? Basta un server raggiungibile.

Firefox si collega in uscita al tuo Linux. Su Internet il server deve offrire HTTPS con un certificato valido. Ogni server indipendente ha il proprio codice; più terminali dello stesso server riusano il medesimo broker.

Sei tu a scegliere quando condividere.

Un server abilitato può leggere e modificare le schede e richiedere schermate. Tutti i server abilitati condividono lo stesso browser. Metti in pausa il controllo quando non vuoi autorizzare azioni. Android può sospendere Firefox: riaprilo per riprendere.
