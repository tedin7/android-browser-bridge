Collega il tuo browser Android

Usa Firefox Android. Nessun ADB, Termux o cavo richiesto.

  1. Installa l’estensione Browser Bridge.
  2. Dal tuo assistente Linux chiedi di abbinare il browser: lo strumento MCP browser_pair genera un collegamento BB1.
  3. Incollalo nell’estensione e abilita il controllo remoto. Puoi disabilitarlo in qualsiasi momento.
Scarica estensione

Versione di sviluppo: il pacchetto non è ancora firmato da Mozilla. Firefox stabile richiede la firma. Per una prova usa Firefox Nightly con installazione da file e le impostazioni per estensioni non firmate.

Quando Android sospende Firefox, il collegamento può interrompersi: riapri il browser per riprendere. Questa estensione controlla le pagine web; le schermate interne del browser e di altre app sono escluse.
